# 🎯 Трекер настроения и продуктивности

Интеллектуальный Telegram-бот для отслеживания ежедневного самочувствия и продуктивности с аналитикой на основе данных.

## 🌟 Возможности

- 📝 **Ежедневная запись показателей:**
  - Настроение (1-5)
  - Часы работы/учебы
  - Часы сна
  - Комментарии

- 📊 **Аналитика и статистика:**
  - Недельные и месячные отчеты
  - Графики динамики
  - Персональные инсайты
  - Корреляции между показателями

- 🔍 **Умные инсайты:**
  - Связь сна и настроения
  - Влияние работы на самочувствие
  - Оптимальный режим дня
  - Лучшие дни недели

## 🚀 Быстрый старт
